# TARA's Daily — 개인 맞춤 채움 레시피

> 이 문서는 에이전트가 "뉴스퍼 채워줘"를 받았을 때 **무엇을, 어디서, 어떤 슬롯에**
> 넣을지 정의한다. 도구 계약(5개)은 AGENTS.md의 표를 따르고, 이 문서는 컨텐츠만
> 다룬다. 렌더링 수술 금지 — 도구 호출로만 채운다.

## 판 구성 (매일 동일 구조)

| 슬롯 | 도구 | 내용 |
|---|---|---|
| 머리글 날짜 | `set_date` | 오늘 (KST) |
| 헤드라인 | `add_headline` | **오늘의 1순위** — 가장 중요한 하나 (마감 임박한 일, 중요한 답변 대기 건, 또는 그날의 핵심 뉴스) |
| 기사 1~3 | `add_story` | 아래 블록 순서대로 |
| 할 일 | `add_task` ×2~6 | 오늘/이번 주 할 일, `due` 필수 지정 |

기사 블록 순서 (위 → 아래):

1. **진행 브리핑** — "지금까지 한 것 / 지금 진행 중" 요약
2. **앞두고 있는 일정** — 다가오는 일정·마감 (D-day 표기)
3. **관심 뉴스** — 관심사별 1~3건, 실제 url+source 첨부

## 컨텐츠 소스 (순서대로 확인)

| 블록 | 소스 | 비고 |
|---|---|---|
| 진행 브리핑 | 최근 세션 작업 기록, vault `채용_지원_현황.md`, 진행 중 프로젝트(뉴스퍼, Etsy, 에세이) | 오래된 진행보다 최근 1~2주 위주 |
| 일정 | 노션 캘린더/스킬, cron 등록된 반복 작업, vault 지원 현황의 마감 | 귀국·재검색 같은 장기 마일스톤도 D-day로 |
| 관심 뉴스 | web_search | 아래 관심사 키워드 사용 |
| 할 일 | vault 지원 현황의 미완료, 위 블록에서 파생된 오늘 할 일 | 진짜 오늘 할 수 있는 것만 |

**관심 뉴스 키워드** (검색 쿼리 후보):
- AI 에이전트 / AI 뉴스 소비자 동향 (Hermes, WebMCP 포함)
- Frontend / React / Next.js 생태계
- 프리랜서·B2B 개발자 시장 (Upwork, 유럽 원격 채용)
- WebMCP 표준 진행 상황 (document.modelContext, 클라이언트 출시)

## 원칙

- **실측만**. 진행 상황·일정은 실제 기록에서; 뉴스는 실제 기사 url+source에서.
  확인 안 되는 것은 "데이터 없음"으로 표기하거나 넣지 않는다.
- 날짜·D-day는 KST 기준으로 실제 계산 (`date` 명령 사용, 추정 금지).
- 컨텐츠는 열린 탭에만 산다 — 백엔드 없음. 개인 문서(이력서·신상) 내용을
  외부 플랫폼에 싣는 일은 없음. 이 판은 로컬 탭이라 제약 위반 없음.
- 할 일은 개수가 아니라 **오늘 실행 가능성**으로 골라낸다 (6개 초과 시 마감순).
- 뉴스 요약은 원문을 훼손하지 않게: 사실만, 과장·예측 금지.
